CHATY — v2

Base de datos: Turso (sin cambios). Las tablas nuevas y las columnas nuevas se crean/migran solas
la primera vez que arranca el servidor (no hay que tocar nada en Turso).

Tiempo real: Upstash Redis (pub/sub). Las llaves están en config.js (repo privado).
  - Cada usuario abre /api/stream (SSE). El servidor se suscribe a su canal "u:<numero>" en Upstash.
  - Al enviar/leer/escribir, el servidor publica el evento y le llega al instante a los demás.
  - Si el SSE se cae, la app vuelve sola a consultar cada 3 s (y cada 20 s como respaldo).

Instalar:  npm install
Subir a Vercel como siempre (git push).
